Proyecto Docker CI

Descripción

Proyecto desarrollado para el curso de Integración Continua.

La aplicación consiste en una API desarrollada con Flask que se comunica con una base de datos PostgreSQL mediante Docker Compose.

Tecnologías utilizadas
Python
Flask
PostgreSQL
Docker
Docker Compose
Git
GitHub
Contenedores
API
Contenedor Flask que expone el puerto 5000.

Base de datos
Contenedor PostgreSQL que expone el puerto 5432.

Ejecución
docker compose up -d

Evidencia de integración
La aplicación responde:

Conexion exitosa con PostgreSQL

confirmando la comunicación entre los contenedores.
